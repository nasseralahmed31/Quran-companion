# رفيق القرآن | Quran Companion

تطبيق Android (Kotlin + Jetpack Compose) لحفظ القرآن ومراجعته بالتكرار المتباعد، يعمل دون إنترنت وبدون حساب.

## الحالة
- [x] المرحلة 1: إعداد المشروع، الثيمات (ليلي/نهاري)، RTL، الصفحة الرئيسية، التنقل السفلي
- [ ] المرحلة 2: Room + نص المصحف الموثوق
- [ ] المراحل 3–8: الحفظ، المراجعة الذكية، الاختبارات، الأهداف والإحصائيات، الإشعارات والنسخ الاحتياطي، الاختبار الشامل

## البناء
افتح المشروع في Android Studio ثم Run، أو: `gradle assembleDebug`.
يبني GitHub Actions ملف APK تلقائيًا عند كل push (قسم Actions ← Artifacts).
