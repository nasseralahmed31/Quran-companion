# رفيق القرآن | Quran Companion

تطبيق Android (Kotlin + Jetpack Compose) لحفظ القرآن ومراجعته بالتكرار المتباعد، يعمل دون إنترنت وبدون حساب.

## الحالة
- [x] المرحلة 1: إعداد المشروع، الثيمات (ليلي/نهاري)، RTL، الصفحة الرئيسية، التنقل السفلي
- [x] المرحلة 2: قاعدة Room للسور والآيات والأجزاء، استيراد نص Tanzil مع تحقق صارم، المصحف (سور/أجزاء/انتقال/قراءة بالصفحات)
- [x] المرحلة 3: تسجيل الحفظ (بالسورة أو بالصفحات) مع التعديل والحذف والسجل، الهدف اليومي، الإنجازات، سجل النشاط، تمييز الآيات في المصحف
- [x] المرحلة 4: المراجعة بالتكرار المتباعد (متأخرة/مستحقة/قريبة/مكتملة)، وما يحتاج مراجعة يأتي قبل غيره ترتيبًا وجدولة، جلسات المراجعة، تعديل المواعيد، اقتراح إعادة الحفظ
- [x] المرحلة 5: الاختبارات (تسميع، إكمال، الآية التالية، المتشابهات) وربط النتيجة بالإتقان والمراجعة
- [x] المرحلة 6: الأهداف ومساعد توزيع الحفظ، الإحصائيات والرسوم، خريطة الحفظ
- [x] كاشف الآيات المتشابهة (تجميع، فروق، اختبارات، ما تخلط بينه)
- [x] المرحلة 7: الإعدادات (المظهر وعدة ثيمات)، تذكيرات WorkManager قابلة للتفعيل والتوقيت، النسخ الاحتياطي والاستعادة (JSON)
- [x] تحسينات القارئ: إخفاء للتسميع، ضغط الآية لتسجيلها، متابعة القراءة، إشارات مرجعية، شريط تنقل، علامات الأرباع والسجدات، تقدير تاريخ ختم الحفظ
- [x] المراجعة التكيفية (تاريخ المراجعة القادمة بحسب الأداء وسجل الأخطاء، وتكرار أكثر للضعيف) وإزاحة المواعيد تلقائيًا عند الفوات
- [x] اختبارات: السورة الصحيحة، بداية مقطع عشوائي، واختبار عشوائي شامل من كامل المحفوظ
- [x] ورد القرآن (تلاوة/حفظ/مراجعة) وخطة ختمة التلاوة وتذكير الورد
- [x] حفظ سابق (منذ زمن) لا يدخل في الوتيرة، وسجل واحد لكل مقطع متصل مرتبًا بترتيب السور
- [ ] خطوط صفحات مصحف المدينة (١٥ سطرًا مطابقة): بانتظار التحقق من المصدر والترخيص
- [ ] المرحلة 8: الاختبار الشامل وتحسين الأداء

## البيانات
انظر `DATA_SOURCES.md`. شغّل `sh scripts/download_quran_data.sh` قبل البناء.

## البناء
افتح المشروع في Android Studio ثم Run، أو: `gradle assembleDebug testDebugUnitTest`.
يبني GitHub Actions ملف APK ويشغّل الاختبارات عند كل push.
